# UC-09.1 — Giám Sát Sức Khỏe Hệ Thống Realtime (System Health Monitoring)

## 📋 1. Bảng Mô Tả Nghiệp Vụ (Business Description Table)

| Mục | Chi Tiết Nghiệp Vụ |
|---|---|
| **Mã Use Case** | `UC-09.1` |
| **Tên Tính Năng** | Giám sát sức khỏe và hiệu năng hệ thống realtime |
| **Actor Chính** | Admin (Quản trị viên) |
| **Mục Tiêu** | Đo đạc các chỉ số RAM Heap/Non-heap, Active Virtual Threads, Peak Threads, Server Uptime và MongoDB Ping Status |
| **API Endpoint** | `GET /api/v1/admin/system/health` |
| **Tiền Điều Kiện** | Yêu cầu quyền `ROLE_ADMIN` |
| **Hậu Điều Kiện** | Trả về `HealthMetricsDTO` |
| **Quy Tắc Nghiệp Vụ** | Thực thi lệnh `ping` MongoDB trực tiếp để đo latency DB realtime |
| **Các Mã Lỗi Có Thể Gặp** | `FORBIDDEN` (403), `UNAUTHORIZED` (401) |

## 🔄 3. Sequence Diagram

```mermaid
sequenceDiagram
    autonumber
    actor Admin as System Administrator
    participant Controller as AdminSystemController
    participant Service as SystemHealthServiceImpl
    participant JVM as Java ManagementFactory MXBean
    participant DB as MongoDB Atlas

    Admin->>Controller: GET /api/v1/admin/system/health
    Controller->>Service: getSystemHealth()
    Service->>JVM: getMemoryMXBean(), getThreadMXBean(), getRuntimeMXBean()
    JVM-->>Service: Memory & Thread Metrics
    
    Service->>DB: executeCommand("{ ping: 1 }")
    DB-->>Service: DB Response ok = 1
    
    Service->>Service: Build HealthMetricsDTO
    Service-->>Controller: HealthMetricsDTO
    Controller-->>Admin: 200 OK (Chi tiết RAM, Threads, Uptime, DB Status)
```
